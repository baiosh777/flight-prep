    Flights

    Flights are stored on this iPad only. Everything works without internet once a flight is loaded.

    Pick the Lido OFP PDF straight from Files and the app builds the flight itself (offline). A prep file from Claude adds the company pages (charts, CCI / AOI, MEL, comms).

    How to useoffline
    1. Claude sends a flight file for every flight (for example EK794_NBJ-DXB_flight.json). Save it to the Files app – or copy it and use Paste flight.
    2. Turnaround: load or paste the return flight with Save as the return flight ticked. It is kept next to the outbound flight and offered on NOW before landing.
    3. Tap Load flight file and pick it. The app opens the flight on the NOW screen.
    4. At take-off tap AIRBORNE NOW (or type the time). Tap waypoint rows as you pass them; tap Done on calls; tap FUEL CHECK after each fuel check.
    5. Your take-off time, ticks and timers stay on this iPad, per flight. Flights older than 5 days are removed automatically.

    Preparation aid only – the OFP, official Emirates documentation and ATC prevail. Times are planned EETs from the T/O time you set; the app does not know the aircraft position.
